## Hi there 👋

**Graphic / UI·UX Designer & Frontend Developer**

시각적인 디자인과 실제로 동작하는 웹 사이의 간격을 줄이는 작업을 합니다.
그래픽 디자인, UI/UX 설계부터 프론트엔드 구현까지 직접 다루며,
**보기 좋은 화면을 만드는 것뿐 아니라 구조적이고 유지보수 가능한 결과물**을 만드는 데 관심이 있습니다.

웹사이트와 콘텐츠를 디자인하고,
필요하면 직접 코드를 작성해 실제 서비스 형태로 구현합니다.

## What I do

* **UI / UX Design**
  웹사이트와 서비스의 정보 구조, 레이아웃, 컴포넌트 및 인터랙션 설계

* **Frontend Development**
  React · TypeScript 기반의 반응형 웹 UI 개발 및 인터랙션 구현

* **Web Publishing**
  HTML · CSS · JavaScript 기반 퍼블리싱과 기존 웹사이트 유지보수

* **Graphic**
  편집·인쇄물, 제안서, 디지털 콘텐츠 디자인

* **Practical Web Maintenance**
  PHP 기반 웹사이트와 CMS 수정, FTP 배포 및 운영 환경 대응

* **Data & Automation**
  반복 업무를 줄이기 위한 간단한 JavaScript / Node.js 스크립트와 데이터 가공
